Projects

Project MPLS-LDP Network (Cisco Devices)

Routing menggunakan MPLS-LDP (Label Distribution Protocol) pada router Cisco menggabungkan efisiensi switching Layer 2 dengan fleksibilitas routing Layer 3. Menggantikan fungsi pencarian next-hop pada Routing Information Table(RIB) menjadi Label Information Table(LIB), LDP membuat router saling berkomunikasi untuk mengaitkan alamat IP tujuan dengan label tertentu. Setelah tabel label terbentuk, router akan meneruskan paket data berdasarkan label tersebut (penerusan hop-by-hop).

Dynamic Routing (OSPF)

OSPF (Open Shortest Path First) protokol routing link-state yang digunakan untuk menghitung jalur terpendek dalam jaringan IP. Protokol ini bekerja dengan membangun peta topologi jaringan secara real-time dan menggunakan algoritma Dijkstra untuk menentukan rute terbaik ke setiap tujuan.
